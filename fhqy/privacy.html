方盒奇遇 隐私政策

更新日期：2026年11月20日　生效日期：2026年11月20日

谢崇鑫（以下简称“我们”）是《方盒奇遇》（以下简称“本游戏”）的运营者，也是本游戏相关个人信息的处理者。我们深知个人信息对您的重要性，并会尽全力保护您的个人信息安全可靠。我们致力于维持您对我们的信任，恪守权责一致、目的明确、选择同意、最少够用、确保安全、主体参与、公开透明等原则，并采取相应的安全保护措施保护您的个人信息。

请您在使用本游戏前，仔细阅读并了解本《隐私政策》。

本政策适用于本游戏的 TapTap Android 版本与 Tap 小游戏版本。两个版本均提供云存档与排行榜功能，但接入方式不同，具体处理范围以对应版本的说明为准；相关功能的数据处理范围、触发时机与控制方式见下文。好友排行榜与云存档是不同功能，不应将排行榜连接成功理解为存档已备份或各版本数据已经互通。

一、我们收集的信息

1. 实名认证与合规标识

Android 版本通过 TapTap SDK 提供实名认证与防沉迷服务，并在设备本地生成、保存随机标识，用于关联合规认证流程；该标识不是 TapTap 用户标识（openId），也不用于关联您的游戏存档。Tap 小游戏的实名认证与防沉迷由 TapTap 宿主平台提供。实名认证所需的姓名、身份证件号码由 TapTap 平台收集与校验，游戏业务不直接收集、存储这些实名信息。TapTap 在认证过程中涉及的账号、设备等信息处理，适用本政策第三部分所列的隐私说明。

2. 设备与网络信息

为保障游戏正常运行、提供版本更新检查及分析游戏使用情况，本游戏接入的 TapTap SDK 及 Tap 小游戏运行环境可能处理系统版本、设备型号、处理器信息、设备内存信息、网络类型、无线网络信息与传感器列表等设备信息，并为认证、账号识别、设备识别和统计目的生成或使用设备标识，例如 Android ID 或由 SDK 生成的标识。Android 版本的更新唤起还可能处理已安装的 TapTap 客户端信息，用于判断客户端及更新入口是否可用；该项指指定客户端信息，不用于收集与此功能无关的已安装应用清单。上述信息项目依据 TapSDK 隐私政策列明，具体处理范围以实际启用的 SDK 功能、设备环境与运行情况为准，用途请参见本政策第三部分及所链接的 TapSDK 隐私政策。本游戏未开启广告标识符采集。

3. 游戏行为与使用情况

您的完整游戏存档、游戏进度、关卡成绩和金币余额主要存储在您的设备本地；云存档的同步范围与内容见本部分第 5 条，排行榜信息见第 6 条。在已启用 TapTap 数据分析的版本中，您完成合规验证并进入游戏后，为了解游戏使用情况、优化关卡难度和改善体验，本游戏可能发送与游戏行为相关的统计事件，包括关卡编号与序号、关卡开始和完成情况、通关星级、操作次数、游戏用时、新手引导完成或跳过情况、提示使用情况、金币奖励或消耗情况、提示道具不足时的当前金币余额，以及装扮解锁和使用情况。

上述统计事件与完整游戏存档不同。统计信息的具体范围以实际启用的功能为准；我们不会通过这些游戏行为事件主动提交您的姓名或身份证件号码。

4. 日志信息

当游戏发生异常时，系统可能生成崩溃日志用于定位问题。本游戏自身不主动上传日志文件。在 Tap 小游戏版本中，运行环境默认会将错误日志、未处理的异常信息，以及包括设备型号、操作系统版本、运行环境版本与设备性能等级在内的运行环境信息自动上报至 TapTap 平台，用于崩溃与异常诊断；该上报由小游戏运行环境实现，不包含您的姓名、身份证件号码、通讯录或本地存档内容。Android 版本中，如所接入的 SDK 启用了异常诊断能力，其日志处理按本政策第三部分的说明执行。相关日志的保存期限确定方法见第四部分。

5. 云存档数据

本游戏提供云存档同步功能，用于在更换设备、重新安装游戏或清除本地数据后恢复游戏进度。Android 版本在您通过 TapTap SDK 完成账号登录授权后使用；Tap 小游戏版本通过 TapTap 宿主平台关联当前账号，无需在游戏内重复登录。小游戏云存档是否可用由宿主平台校验，不以好友榜连接成功为依据；同步时机与开关见本部分下文。

Android 版本启用云存档后，本游戏会获取您的 TapTap 账号标识（openId），用于关联本机与云端存档，并使用该标识生成的哈希值校验存档归属。Tap 小游戏版本使用宿主提供的当前用户云存档接口，本游戏不为此直接获取 openId，也不以自行生成的玩家标识或账号哈希替代平台认证；云端存档与玩家账号的关联由 TapTap 平台处理。

本游戏会将完整游戏存档同步至 TapTap 云存档服务，内容包括游戏进度与成绩、金币及提示道具、装扮解锁与装备、登录与奖励记录，以及存档时间，用于备份和恢复。

上传的存档不包含您的姓名、身份证件号码、手机号、通讯录或位置信息。音乐、音效与操作方式等设置仅保存在设备本地，不参与云存档同步。

自动同步默认开启。Android 版本完成云存档所需的账号登录授权后，Tap 小游戏版本在宿主云存档接口可用时，会在进入主页、本地存档变更后回到主页，以及重新切换回游戏时尝试同步；小游戏不需要您先打开云存档面板或连接好友榜才触发同步。遇到需要您选择的本机与云端进度差异时，会先提示确认，不直接覆盖。您可以在“设置—云存档—管理云存档”中关闭当前设备的自动同步，关闭后不再自动上传或从云端恢复进度，但仍可主动手动同步。该开关仅保存在当前设备，不会随云存档同步至其他设备。关闭自动同步不会删除此前已上传的存档；删除云端备份的方式见第四部分。

6. 排行榜与好友关系信息

当您主动连接排行榜并完成所需的 TapTap 登录、隐私同意及好友关系授权后，本游戏会向 TapTap 排行榜服务提交您的总星数和闯关综合分。综合分由最高已通关主线关卡，以及第 1 关至该关各关最佳成功通关用时之和计算，用于按进度优先、同进度用时较短优先的规则排序。个人纪录仍保存在本机；排行榜成绩不是完整存档备份。

为关联成绩、计算排名与展示榜单，TapTap 服务、SDK 及官方面板会处理必要的账号标识（如 SDK 返回的 openId、unionId）、昵称、头像、成绩和排名；好友榜还需要使用您的 TapTap 好友关系来筛选好友成绩。本游戏不为此读取手机通讯录，也未接入好友聊天功能。

榜单成绩及相关昵称、头像、排名可能按榜单的发布范围向其他玩家展示。官方面板可以在好友榜与总榜之间切换，好友榜入口不意味着成绩仅对好友可见，实际可见范围以榜单设置及您的授权为准。

您可以不连接排行榜；拒绝好友关系授权不影响本地单机游玩和个人纪录查看。退出榜单、清除本地数据、退出账号或停止授权，不会自动删除此前已提交的成绩。当前游戏未提供排行榜成绩的一键删除入口；如需查询、更正、删除相关信息或撤回授权，请通过本政策末尾的联系邮箱提出请求，我们将核实并与 TapTap 协调处理、反馈结果。

7. 添加到桌面（仅 Tap 小游戏）

仅在您主动使用“添加到桌面”入口时，本游戏才会通过 TapTap 宿主查询桌面小组件及当前游戏的添加状态，并按您的请求调用添加接口。返回状态仅用于显示操作反馈，不作为账号身份或云存档归属凭据，不产生游戏奖励。iOS 需要您在 Safari 中手动完成添加；接口回调不等于您已完成全部操作。

三、第三方 SDK

为实现游戏功能，Android 版本按实际启用功能使用由易玩（上海）网络科技有限公司提供的以下 TapTap SDK 模块；Tap 小游戏使用 Tap 小游戏插件及宿主平台提供的对应能力，不在小游戏中加载 Android 原生 SDK：

  • TapSDK Core：提供 SDK 基础运行能力及相关数据分析能力；
  • TapSDK Login：提供 TapTap 账号登录授权能力，用于云存档账号关联、存档归属校验及排行榜账号关联；
  • TapSDK Compliance：提供实名认证与防沉迷服务；
  • TapSDK Update：检查游戏版本，并在需要时引导您通过 TapTap 更新游戏；
  • TapSDK CloudSave（Android 版本）：您授权 TapTap 账号登录后，将游戏存档上传至云端并在需要时恢复；Tap 小游戏版本使用宿主平台提供的云存档能力。
  • TapSDK Leaderboard：提交成绩、计算排名并展示官方总榜或好友榜；好友关系的使用范围见第一部分第 6 条。

其中，TapTap 数据分析服务用于接收和分析本政策第一部分所述的游戏行为统计信息，帮助我们了解游戏使用情况并改进体验。TapTap SDK 可能处理设备与网络信息、由 SDK 提供的设备标识及 TapTap 账号标识（openId），具体范围以实际启用的功能和运行情况为准；本游戏未开启广告标识符采集。

TapTap 云存档服务由易玩（上海）网络科技有限公司提供，用于存储与恢复您的游戏存档。Android 版本通过 TapTap SDK 登录关联账号，Tap 小游戏版本使用宿主关联的当前账号。该服务的存档内容、账号关联方式、同步时机及存储与处理规则，见本政策第一部分第 5 条、第四部分及第六部分的相关说明。

TapTap 排行榜服务由易玩（上海）网络科技有限公司提供，处理范围与用途见第一部分第 6 条。在 Android 官方榜单面板中主动使用分享或保存排行榜图片功能时，SDK 可能按系统版本及实际功能使用存储权限，用于保存您选择的分享图片；相关权限不用于云存档账号识别或读取手机通讯录。Tap 小游戏的榜单由宿主平台提供官方面板，相关界面与功能以平台实际提供为准；小游戏业务不为此直接申请存储或相册权限，也不读取手机通讯录。

本游戏及所接入的 SDK 为联网认证、云存档同步、版本检查和操作反馈使用互联网访问、网络状态与振动等权限。Android 版本的更新唤起会检查游戏版本及已安装的 TapTap 客户端信息，并在需要时引导您通过 TapTap 更新游戏；根据设备环境和更新方式，SDK 在引导安装 TapTap 客户端时可能涉及安装应用权限，您可以根据系统提示决定是否授权。该权限的用途是安装 TapTap 客户端，不是获取您的电话、位置、通讯录或本地存档内容。

第三方名称：易玩（上海）网络科技有限公司。有关其个人信息处理规则、联系方式及用户权利，请参见 TapSDK 隐私政策 及 TapTap 隐私政策。

四、信息的存储与安全

  • 合规认证结果与相关标识由 TapTap 平台按其规则处理；
  • 完整游戏存档与游戏进度主要存储在您的设备本地，卸载游戏或清除本地数据可能导致存档丢失；
  • 通过对应版本的账号关联方式上传的云存档，由 TapTap 云存档服务存储和处理。您可以在游戏内的云存档管理中删除当前 TapTap 账号在本游戏中的云端备份；删除前需再次确认，本游戏会先关闭当前设备的自动同步，再通过对应版本的 TapTap 接口发起删除并检查结果。本机游戏进度与替换前备份不会因此删除；成功删除的云端备份无法通过云存档恢复。手动同步、重新开启自动同步，或其他设备继续同步时，仍可能重新生成云端备份。云存档在您使用该功能期间保存；您删除云端备份、注销用于关联存档的 TapTap 账号，或本游戏停止提供云存档功能后，按 TapTap 云存档服务的规则处理，本游戏将依法处理相关数据，并与 TapTap 协调必要的删除事宜；
  • 通过 TapTap 数据分析服务发送的统计事件，以及由 SDK 或小游戏运行环境上报的异常诊断日志，由 TapTap 对应服务处理和保存。保存期限确定方法：根据相关问题是否完成定位与修复验证、对应关卡或体验分析是否完成，以及是否仍需保留可关联到个人的原始数据，确定必要的保留时间；目的已实现、无法实现或原始数据不再必要时，依法删除或匿名化处理。涉及 TapTap 保存的数据，我们将与其协调必要处置。法律法规规定的保存期限未届满，或删除从技术上难以实现的，依法停止除存储和采取必要安全保护措施之外的处理；
  • 已提交的排行榜成绩及相关账号信息由 TapTap 排行榜服务保存和处理，展示范围见第一部分第 6 条；排行榜成绩在对应榜单存续期间保存，榜单关闭、您删除相关信息或本游戏停止使用该服务后，按 TapTap 排行榜服务的规则处理。清除本机进度或删除云存档不会同步删除排行榜成绩。相关查询、更正或删除请求按第六部分处理；
  • 本游戏与 TapTap 服务之间的数据传输使用加密通道；云存档的存储、访问控制与删除按 TapTap 云存档服务的规则实施；
  • 我们不建立独立的用户数据库，不将上述信息用于本政策未载明的用途，也不将其用于定向推送或个性化广告。

如出现个人信息泄露、篡改、丢失，或存在发生上述事件的可能，我们将立即采取补救措施，并按法律要求向主管部门报告、通知受影响的用户。通知将说明受影响的数据类别、事件原因及可能影响、我们的补救行动、您可采取的防护措施，以及联系渠道；我们将根据实际情况，通过本页面公告或可用的联系方式向您告知。

如果补救措施已能有效避免事件造成危害，我们可依法不向个人另行通知；如主管部门要求通知，我们仍将按要求执行。

五、信息的共享、转让与公开披露

为实现合规认证、云存档同步、游戏更新、数据分析及排行榜等功能，本游戏会使用本政策第三部分所列的 TapTap SDK 或小游戏宿主能力，并在实现相应功能所需范围内由 TapTap 处理相关信息。排行榜可能涉及向其他玩家展示信息，范围见第一部分第 6 条。

除本政策已说明的情形外，我们不会向其他第三方共享、转让或公开披露您的个人信息；法律法规另有规定，或已依法取得您的单独同意的除外。

六、您的权利

  • 游戏本地数据：您可以通过设备提供的应用管理功能清除本游戏的本地数据，清除后本地存档可能无法恢复；此举不会删除此前已上传的统计信息与云存档；
  • 云存档：您可以在游戏内的云存档面板查看当前同步状态，并在出现需要您确认的存档冲突时，选择保留本机或云端进度；您也可以进入“管理云存档”，关闭本机自动同步或删除云端备份，具体影响见第四部分。删除云存档不会注销 TapTap 账号，也不会删除此前已上传的统计信息。如需进一步协助，可通过本政策末尾的联系邮箱提出请求。我们将在核实后处理您的请求；涉及 TapTap 服务的，将与其协调，并向您说明必要的操作步骤、处理结果及对相关功能的影响。提交请求不代表相关数据已删除，具体处理结果将向您反馈；

七、未成年人保护

本游戏建议 8 周岁以上用户使用。我们按照《国家新闻出版署关于进一步严格管理切实防止未成年人沉迷网络游戏的通知》的要求，对未成年人的游戏时段与时长进行限制。未满 18 周岁的未成年人应在监护人指导下阅读并同意本政策；未满 14 周岁的儿童还应在监护人陪同下阅读本部分专门规则及 TapTap《儿童个人信息保护规则》，并在取得监护人所需同意后使用本游戏。

本游戏不以不满 14 周岁的儿童为主要受众。儿童个人信息属于敏感个人信息，应在具有特定目的、充分必要性并依法取得监护人的相应单独同意后处理。儿童使用本游戏涉及本地游戏进度、第一部分所述运行与诊断信息，以及通过对应版本账号关联方式使用的云存档与排行榜信息；这些信息分别用于保存和恢复进度、保障运行、诊断异常、分析并改善游戏体验，以及展示获授权的榜单。不将儿童个人信息用于营销推广、用户画像或定向推送；保存期限按第四部分的确定方法执行。儿童使用实名认证与防沉迷服务所需的身份信息，由 TapTap 平台按其规则收集与校验，本游戏不直接收集、存储。

儿童使用排行榜时，其昵称、头像、成绩和排名的展示范围见第一部分第 6 条，相关信息可能按榜单设置向其他玩家展示，并非仅由 TapTap 服务内部处理。公开展示儿童个人信息，应依法取得监护人的相应单独同意；未取得所需同意，不得提供相应的公开展示。除上述依法授权的排行榜展示外，我们不向本政策第三部分所列 TapTap 服务以外的其他第三方共享、转让或公开披露儿童个人信息。

如您是儿童的监护人，需要查询、更正或删除该儿童的个人信息，或撤回此前的同意，可通过本政策末尾的联系邮箱与我们联系。我们将在核实监护人身份后处理，并在必要时协助您向 TapTap 提出相应请求。
