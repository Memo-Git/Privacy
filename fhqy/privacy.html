方盒奇遇 隐私政策

更新日期：2026年11月5日　生效日期：2026年11月5日

【开发者姓名】（以下简称“我们”）是《方盒奇遇》（以下简称“本游戏”）的运营者。我们深知个人信息对您的重要性，并会尽全力保护您的个人信息安全可靠。我们致力于维持您对我们的信任，恪守权责一致、目的明确、选择同意、最少够用、确保安全、主体参与、公开透明等原则，并采取相应的安全保护措施保护您的个人信息。

请您在使用本游戏前，仔细阅读并了解本《隐私政策》。

一、我们收集的信息

1. 账号与实名信息

本游戏通过 TapTap SDK 提供账号登录与实名认证服务。当您使用 TapTap 账号登录时，我们会获取您的 TapTap 用户标识（openId）。实名认证所需的姓名、身份证件号码由 TapTap 平台收集与校验，我们不直接收集、不存储您的身份证件信息，仅接收实名认证结果（是否通过、年龄段）。

2. 设备信息

为保障游戏正常运行与问题排查，我们可能获取设备型号、操作系统版本、处理器架构、屏幕分辨率等信息。上述信息不包含可直接识别您个人身份的内容。

3. 游戏数据

您的游戏进度、关卡成绩、金币等数据默认存储在您的设备本地，不会上传至我们的服务器。

4. 日志信息

当游戏发生异常时，系统可能生成崩溃日志用于定位问题。我们不会主动上传此类日志。

二、我们如何使用信息

  • 完成 TapTap 账号登录与实名认证；
  • 落实未成年人防沉迷要求，包括游戏时段与时长限制；
  • 保障游戏运行、适配设备与修复缺陷；
  • 遵守法律法规的规定。

三、第三方 SDK

本游戏接入 TapTap SDK，由易玩（上海）网络科技有限公司提供，包含以下模块：

  • TapSDK Core：基础运行能力；
  • TapSDK Login：TapTap 账号登录；
  • TapSDK Compliance：实名认证与防沉迷。

上述 SDK 可能收集设备信息、网络信息与 TapTap 账号标识，用于登录、实名认证与防沉迷校验。其个人信息处理规则请参见 TapTap 隐私政策：https://www.taptap.cn/privacy。

四、信息的存储

  • 账号标识与实名认证结果由 TapTap 平台按其隐私政策存储；
  • 游戏进度等数据存储在您的设备本地，卸载游戏即被删除；
  • 我们不建立独立的用户数据库，不将上述信息用于本政策未载明的用途。

五、信息的共享、转让与公开披露

我们不会向第三方共享、转让或公开披露您的个人信息，但法律法规另有规定或事先取得您同意的除外。

六、您的权利

  • 查询、更正您的游戏数据：可通过游戏内设置或清除本地数据实现；
  • 注销账号：可通过 TapTap 平台提供的账号注销功能操作；
  • 其他请求：可通过本政策末尾的联系方式与我们联系，提出查询、删除个人信息等请求。

七、未成年人保护

本游戏建议 8 周岁以上用户使用。我们按照《国家新闻出版署关于进一步严格管理切实防止未成年人沉迷网络游戏的通知》的要求，对未成年人的游戏时段与时长进行限制。未满 14 周岁的未成年人使用本游戏，应在监护人陪同下阅读本政策，并在取得监护人同意后使用。

八、政策更新

我们可能适时更新本政策。更新后，我们会在游戏内或本页面公布。若您继续使用本游戏，即表示您同意更新后的政策。
