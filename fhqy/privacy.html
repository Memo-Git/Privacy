方盒奇遇 隐私政策

更新日期：2026年11月7日　生效日期：2026年11月7日

谢崇鑫（以下简称“我们”）是《方盒奇遇》（以下简称“本游戏”）的运营者。我们深知个人信息对您的重要性，并会尽全力保护您的个人信息安全可靠。我们致力于维持您对我们的信任，恪守权责一致、目的明确、选择同意、最少够用、确保安全、主体参与、公开透明等原则，并采取相应的安全保护措施保护您的个人信息。

请您在使用本游戏前，仔细阅读并了解本《隐私政策》。

一、我们收集的信息

1. 实名认证与合规标识

本游戏通过 TapTap SDK 提供实名认证与防沉迷服务，并在设备本地生成、保存随机标识，用于关联合规认证流程；该标识不是 TapTap 用户标识（openId），本游戏不使用 openId 绑定本地游戏存档。实名认证所需的姓名、身份证件号码由 TapTap 平台收集与校验，游戏业务不直接收集、存储这些实名信息，而是根据 SDK 提供的认证结果控制是否允许进入游戏。TapTap SDK 在认证过程中涉及的账号、设备等信息处理，适用本政策第三部分所列的 SDK 隐私说明。

2. 设备与网络信息

为保障游戏正常运行、提供版本更新检查及分析游戏使用情况，本游戏接入的 TapTap SDK 可能处理系统版本、设备型号、处理器信息、设备内存信息、网络类型、无线网络信息与传感器列表等设备信息，并为认证、设备识别和统计目的生成或使用设备标识，例如 Android ID 或由 SDK 生成的标识。上述信息项目依据 TapSDK 隐私政策列明，具体处理范围以实际启用的 SDK 功能、设备环境与运行情况为准，用途请参见本政策第三部分及所链接的 TapSDK 隐私政策。本游戏未开启广告标识符采集。

3. 游戏行为与使用情况

您的完整游戏存档、游戏进度、关卡成绩和金币余额主要存储在您的设备本地。在您完成合规验证并进入游戏后，为了解游戏使用情况、优化关卡难度和改善体验，本游戏可能通过 TapTap 数据分析服务发送与游戏行为相关的统计事件，包括关卡编号与序号、关卡开始和完成情况、通关星级、操作次数、游戏用时、新手引导完成或跳过情况、提示使用情况、金币奖励或消耗情况、提示道具不足时的当前金币余额，以及装扮解锁和使用情况。

上述统计事件与完整游戏存档不同。统计信息的具体范围以实际启用的功能为准；我们不会通过这些游戏行为事件主动提交您的姓名或身份证件号码。

4. 日志信息

当游戏发生异常时，系统可能生成崩溃日志用于定位问题。我们不会主动上传此类日志。

二、我们如何使用信息

  • 提供实名认证并执行防沉迷校验；
  • 落实未成年人防沉迷要求，包括游戏时段与时长限制；
  • 保障游戏运行、适配设备与修复缺陷；
  • 分析游戏使用情况，优化新手引导、关卡难度和游戏体验；
  • 检查游戏版本，并在需要时引导您通过 TapTap 更新游戏；
  • 遵守法律法规的规定。

三、第三方 SDK

为实现游戏功能，本游戏接入由易玩（上海）网络科技有限公司提供的 TapTap SDK。根据本游戏实际使用的功能，相关模块包括：

  • TapSDK Core：提供 SDK 基础运行能力及相关数据分析能力；
  • TapSDK Login：随相关 SDK 依赖集成，提供账号相关基础能力；本游戏当前以合规认证结果控制游戏访问；
  • TapSDK Compliance：提供实名认证与防沉迷服务；
  • TapSDK Update：检查游戏版本，并在需要时引导您通过 TapTap 更新游戏。

其中，TapTap 数据分析服务用于接收和分析本政策第一部分所述的游戏行为统计信息，帮助我们了解游戏使用情况并改进体验。TapTap SDK 可能处理设备与网络信息、由 SDK 提供的设备标识及 TapTap 账号标识，具体范围以实际启用的功能和运行情况为准；本游戏未开启广告标识符采集。

本游戏及所接入的 SDK 为联网认证、版本检查和操作反馈使用互联网访问、网络状态与振动等权限。更新唤起功能会检查游戏版本，并在需要时引导您通过 TapTap 更新游戏；根据设备环境和更新方式，SDK 在引导安装 TapTap 客户端时可能涉及安装应用权限，您可以根据系统提示决定是否授权。该权限的用途是安装 TapTap 客户端，不是获取您的电话、位置、通讯录或本地存档内容。

第三方名称：易玩（上海）网络科技有限公司。有关其个人信息处理规则、联系方式及用户权利，请参见 TapSDK 隐私政策 及 TapTap 隐私政策。

四、信息的存储

  • 合规认证结果与相关标识由 TapTap 平台按其规则处理；
  • 完整游戏存档与游戏进度主要存储在您的设备本地，卸载游戏或清除本地数据可能导致存档丢失；
  • 通过 TapTap 数据分析服务发送的统计事件由相应服务处理和保存，仅在实现处理目的所必需的最短时间内保留，超出必要期限后删除或匿名化处理；
  • 我们不建立独立的用户数据库，不将上述信息用于本政策未载明的用途。

五、信息的共享、转让与公开披露

为实现合规认证、游戏更新和数据分析等功能，本游戏会接入本政策第三部分所列的 TapTap SDK，并在实现相应功能所需范围内由 TapTap 处理相关信息。

除本政策已说明的情形外，我们不会向其他第三方共享、转让或公开披露您的个人信息；法律法规另有规定，或已依法取得您的单独同意的除外。

六、您的权利

  • 游戏本地数据：您可以通过设备提供的应用管理功能清除本游戏的本地数据，清除后本地存档可能无法恢复；此举不会删除此前已上传的统计信息；
  • 暂时阻止上传：如您的设备支持针对本游戏限制联网，您可以通过系统设置暂时阻止网络上传。断网不等于撤回同意，也不保证 SDK 停止在本地生成或记录统计数据，恢复联网后仍可能继续上传统计事件。卸载本游戏会停止本应用在该设备上的运行，但不会自动删除此前已上传的信息；
  • 撤回同意、停止统计、查询与删除：您可通过本政策末尾的联系邮箱提出撤回同意、停止后续统计，或查询、更正、删除已收集个人信息的请求。我们将依法核实、处理并反馈结果；涉及由 TapTap 处理的信息，我们将协助您向其提出请求，并说明必要的操作步骤及对相关功能的影响。发送请求、断网或清除本地数据本身，不代表既有统计数据已从服务端删除，具体处理结果将向您反馈；
  • 注销账号：可通过 TapTap 平台提供的账号注销功能操作。

七、未成年人保护

本游戏建议 8 周岁以上用户使用。我们按照《国家新闻出版署关于进一步严格管理切实防止未成年人沉迷网络游戏的通知》的要求，对未成年人的游戏时段与时长进行限制。未满 18 周岁的未成年人应在监护人指导下阅读并同意本政策；未满 14 周岁的儿童还应在监护人陪同下阅读 《儿童个人信息保护规则》，并在取得监护人同意后使用本游戏。

八、政策更新

我们可能根据游戏功能或个人信息处理情况的变化更新本政策。更新后，我们会通过游戏内提示或本页面向您告知。对于依法需要重新取得您同意的变更，我们将在处理相关信息前征求您的同意。
